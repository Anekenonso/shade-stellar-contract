# Contracts

Per-contract reference pages, one per crate under [`contracts/`](../../contracts), written from the [contract reference template](../contributing/templates/contract-reference-template.md).

- [Shade](shade.md) (`contracts/shade/`) — the payment gateway hub.
- [Account](account.md) (`contracts/account/`) — the per-merchant vault the hub deploys.

Escrow, subscription, ticketing and crowdfunding contracts are not part of the gateway. They live in [`example/`](../../example/README.md), outside this workspace and CI.
