# Makefile & Developer Scripts Reference

This document provides a complete technical reference for the Shade Protocol build system, Makefile targets, configuration variables, developer automation scripts, and pre-commit hook policies.

---

## 1. Overview & Toolchain Requirements

The repository's automation wraps `cargo`, `rustc`, `pre-commit`, and the official `stellar` / `soroban` CLI to deliver deterministic compilation, testing, optimization, and on-chain lifecycle management.

### Required Prerequisites

| Tool | Minimum Version | Installation Command | Purpose |
| :--- | :--- | :--- | :--- |
| **Rust Toolchain** | `stable` | `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs \| sh` | Compiler and package manager |
| **WASM Target** | `wasm32-unknown-unknown` | `rustup target add wasm32-unknown-unknown` | Cross-compilation to WebAssembly |
| **Stellar CLI** | `v21.0.0+` | `cargo install --locked stellar-cli --features opt` | Deployment, optimization, invocation |
| **Python & Pip** | `3.9+` | Standard system package | Runs pre-commit git hooks |
| **Pre-commit** | `v3.0.0+` | `pip install pre-commit` | Client-side git hook framework |

## 2. Configuration Variables

The `Makefile` defines several top-level variables that control target network environments, administrator keys, and binary artifact paths:

```makefile
NETWORK ?= testnet
ADMIN ?=
SHADE_WASM = target/wasm32-unknown-unknown/release/shade.wasm
ACCOUNT_WASM = target/wasm32-unknown-unknown/release/account.wasm
SHADE_WASM_OPT = target/wasm32-unknown-unknown/release/shade.optimized.wasm
ACCOUNT_WASM_OPT = target/wasm32-unknown-unknown/release/account.optimized.wasm
STELLAR_DIR = .stellar
```

### Variable Reference

| Variable | Default Value | Accepted Values | Description | Required By |
| :--- | :--- | :--- | :--- | :--- |
| **`NETWORK`** | `testnet` | `testnet`, `futurenet`, `local`, `mainnet` | Target Stellar network configured in `stellar network` profiles. | All `deploy-*`, `init-*`, `pause-*`, query targets |
| **`ADMIN`** | *empty* | Valid Stellar public key (`G...`) or alias | Administrator account address holding protocol permissions. | `init-shade`, `pause-shade`, `unpause-shade` |
| **`SHADE_WASM`** | `target/.../shade.wasm` | File path | Unoptimized raw WebAssembly binary of the central `shade` contract. | `optimize` |
| **`ACCOUNT_WASM`** | `target/.../account.wasm`| File path | Unoptimized raw WebAssembly binary of the `account` contract. | `optimize` |
| **`SHADE_WASM_OPT`** | `target/.../shade.optimized.wasm` | File path | Stripped and size-optimized WASM for `shade`. | `deploy-shade`, `upgrade-shade` |
| **`ACCOUNT_WASM_OPT`**| `target/.../account.optimized.wasm`| File path | Stripped and size-optimized WASM for `account`. | `deploy-account` |
| **`STELLAR_DIR`** | `.stellar` | Directory path | Local storage directory for deployed contract IDs and install hashes. | All deployment and invocation targets |

## 3. Directory Layout for Deployment Artifacts (`.stellar/`)

Deployment and lifecycle targets store output state in the root `.stellar/` directory. These files are git-ignored and used by subsequent commands:

| Artifact File | Generated By | Consumed By | Content |
| :--- | :--- | :--- | :--- |
| **`.stellar/shade_contract_id.txt`** | `make deploy-shade` | `init-shade`, `pause-shade`, `unpause-shade`, `get-admin-shade`, `is-paused-shade` | 56-character Stellar Contract ID (`C...`) |
| **`.stellar/account_contract_id.txt`** | `make deploy-account` | Merchant onboarding, hub initialization | 56-character Stellar Contract ID (`C...`) |
| **`.stellar/shade_new_wasm_hash.txt`** | `make upgrade-shade` | Admin upgrade transaction payload | 64-character hex SHA-256 WASM bytecode hash |

## 4. Complete Makefile Target Catalog

### Development & Quality Assurance Targets

#### `make help`
- **Purpose**: Displays the help menu listing all available targets and descriptions.
- **Dependencies**: None.
- **Side Effects**: Reads `Makefile` via `grep` and prints formatted output to `stdout`.

#### `make build`
- **Purpose**: Compiles all workspace contracts to `wasm32-unknown-unknown` in release mode.
- **Dependencies**: None.
- **Required Variables**: None.
- **Side Effects**: Generates raw unoptimized WASMs in `target/wasm32-unknown-unknown/release/`. Prints file sizes.
- **Command**:
  ```bash
  cargo build --target wasm32-unknown-unknown --release
  ```

#### `make test`
- **Purpose**: Executes the complete test suite across all workspace contracts.
- **Dependencies**: None.
- **Required Variables**: None.
- **Side Effects**: Runs unit, integration, and mock host simulation tests.
- **Command**:
  ```bash
  cargo test --all
  ```

#### `make optimize`
- **Purpose**: Strips debug symbols, optimizes WebAssembly byte code, and minimizes contract gas footprint.
- **Dependencies**: `build`
- **Required Variables**: None.
- **Side Effects**: Produces `shade.optimized.wasm` and `account.optimized.wasm`.
- **Command**:
  ```bash
  stellar contract optimize --wasm target/wasm32-unknown-unknown/release/shade.wasm
  stellar contract optimize --wasm target/wasm32-unknown-unknown/release/account.wasm
  ```

#### `make fmt`
- **Purpose**: Applies canonical Rust formatting across all contracts and test harnesses.
- **Dependencies**: None.
- **Required Variables**: None.
- **Side Effects**: Re-formats `.rs` files in place according to `rustfmt.toml`.
- **Command**:
  ```bash
  cargo fmt --all
  ```

#### `make lint`
- **Purpose**: Runs the Clippy static analysis tool with strict warnings-as-errors flags.
- **Dependencies**: None.
- **Required Variables**: None.
- **Side Effects**: Analyzes code for idioms, safety patterns, and dead code. Fails on any warning.
- **Command**:
  ```bash
  cargo clippy --all-targets --all-features -- -D warnings
  ```

#### `make clean`
- **Purpose**: Purges all build targets, cached compilations, and local deployment records.
- **Dependencies**: None.
- **Required Variables**: None.
- **Side Effects**: Deletes `target/` and `.stellar/`.
- **Command**:
  ```bash
  cargo clean
  rm -rf .stellar
  ```

#### `make dev-setup`
- **Purpose**: Verifies local toolchain readiness by running a fresh build and full test execution.
- **Dependencies**: `build`, `test`.
- **Required Variables**: None.
- **Side Effects**: Produces build artifacts and confirms all tests pass.

#### `make ci`
- **Purpose**: Complete continuous integration verification pipeline.
- **Dependencies**: `lint`, `test`, `build`.
- **Required Variables**: None.
- **Side Effects**: Fails if linting fails, tests fail, or compilation errors occur.

### Deployment Targets

#### `make deploy-shade [NETWORK=<network>]`
- **Purpose**: Compiles, optimizes, and deploys the central `shade` contract to the specified network.
- **Dependencies**: `optimize`, `check-network`, `$(STELLAR_DIR)`.
- **Required Variables**: `NETWORK` (defaults to `testnet`). Requires configured `default` Stellar CLI identity.
- **Side Effects**:
  - Broadcasts contract creation transaction.
  - Writes deployed contract ID to `.stellar/shade_contract_id.txt`.
- **Command**:
  ```bash
  stellar contract deploy \
    --wasm target/wasm32-unknown-unknown/release/shade.optimized.wasm \
    --network $(NETWORK) \
    --source-account default \
    > .stellar/shade_contract_id.txt
  ```

#### `make deploy-account [NETWORK=<network>]`
- **Purpose**: Compiles, optimizes, and deploys the template `account` contract to the specified network.
- **Dependencies**: `optimize`, `check-network`, `$(STELLAR_DIR)`.
- **Required Variables**: `NETWORK` (defaults to `testnet`).
- **Side Effects**:
  - Broadcasts contract creation transaction.
  - Writes deployed contract ID to `.stellar/account_contract_id.txt`.
- **Command**:
  ```bash
  stellar contract deploy \
    --wasm target/wasm32-unknown-unknown/release/account.optimized.wasm \
    --network $(NETWORK) \
    --source-account default \
    > .stellar/account_contract_id.txt
  ```

#### `make deploy-all [NETWORK=<network>]`
- **Purpose**: Orchestrates sequential deployment of both `shade` and `account` contracts.
- **Dependencies**: `deploy-shade`, `deploy-account`.
- **Required Variables**: `NETWORK`.
- **Side Effects**: Both `.stellar/shade_contract_id.txt` and `.stellar/account_contract_id.txt` are created.

#### `make deploy-testnet`
- **Purpose**: Convenience wrapper forcing `NETWORK=testnet` before running `deploy-all`.
- **Dependencies**: `deploy-all`.
- **Side Effects**: Deploys all configured contracts to Stellar Testnet.

#### `make deploy-futurenet`
- **Purpose**: Convenience wrapper forcing `NETWORK=futurenet` before running `deploy-all`.
- **Dependencies**: `deploy-all`.
- **Side Effects**: Deploys all configured contracts to Stellar Futurenet.

### Contract Initialization & Administration Targets

#### `make init-shade ADMIN=<address> [NETWORK=<network>]`
- **Purpose**: Initializes the deployed `shade` contract with its root administrator address.
- **Dependencies**: `check-admin`, `check-network`.
- **Prerequisites**: `.stellar/shade_contract_id.txt` must exist.
- **Required Variables**: `ADMIN` (Stellar public key, e.g. `GBRA...`).
- **Side Effects**: Sets `DataKey::Admin` in contract storage. Fails if already initialized.
- **Command**:
  ```bash
  stellar contract invoke \
    --id $(cat .stellar/shade_contract_id.txt) \
    --network $(NETWORK) \
    --source-account default \
    -- initialize --admin $(ADMIN)
  ```

#### `make pause-shade ADMIN=<address> [NETWORK=<network>]`
- **Purpose**: Invokes emergency stop on the deployed `shade` contract.
- **Dependencies**: `check-admin`, `check-network`.
- **Prerequisites**: `.stellar/shade_contract_id.txt` must exist. Caller must be the current admin.
- **Required Variables**: `ADMIN`.
- **Side Effects**: Sets contract pause flag to `true`, blocking invoice creation and settlements.
- **Command**:
  ```bash
  stellar contract invoke \
    --id $(cat .stellar/shade_contract_id.txt) \
    --network $(NETWORK) \
    --source-account default \
    -- pause --admin $(ADMIN)
  ```

#### `make unpause-shade ADMIN=<address> [NETWORK=<network>]`
- **Purpose**: Restores normal operation on a paused `shade` contract.
- **Dependencies**: `check-admin`, `check-network`.
- **Prerequisites**: `.stellar/shade_contract_id.txt` must exist. Caller must be the current admin.
- **Required Variables**: `ADMIN`.
- **Side Effects**: Sets contract pause flag to `false`.
- **Command**:
  ```bash
  stellar contract invoke \
    --id $(cat .stellar/shade_contract_id.txt) \
    --network $(NETWORK) \
    --source-account default \
    -- unpause --admin $(ADMIN)
  ```

#### `make upgrade-shade [NETWORK=<network>]`
- **Purpose**: Compiles, optimizes, and installs new contract WASM bytecode onto the network.
- **Dependencies**: `optimize`, `check-network`.
- **Prerequisites**: `.stellar/shade_contract_id.txt` must exist.
- **Side Effects**:
  - Installs bytecode on-chain.
  - Writes new WASM hash to `.stellar/shade_new_wasm_hash.txt`.
- **Command**:
  ```bash
  stellar contract install \
    --wasm target/wasm32-unknown-unknown/release/shade.optimized.wasm \
    --network $(NETWORK) \
    --source-account default \
    > .stellar/shade_new_wasm_hash.txt
  ```

### Query Targets (Read-Only)

#### `make get-admin-shade [NETWORK=<network>]`
- **Purpose**: Queries the current root administrator address of the deployed `shade` contract.
- **Dependencies**: `check-network`.
- **Prerequisites**: `.stellar/shade_contract_id.txt` must exist.
- **Side Effects**: Prints administrator address to `stdout`.

#### `make is-paused-shade [NETWORK=<network>]`
- **Purpose**: Queries whether the `shade` contract is currently paused.
- **Dependencies**: `check-network`.
- **Prerequisites**: `.stellar/shade_contract_id.txt` must exist.
- **Side Effects**: Prints boolean (`true` or `false`) to `stdout`.

## 5. Developer Scripts & Pre-Commit Hook Policies

### `scripts/setup-hooks.sh`

The setup script automates the installation of repository pre-commit hooks to safeguard against secrets leakage, linting errors, and merge conflicts.

```bash
# Run setup script
bash scripts/setup-hooks.sh
```

**Actions Executed**:
1. Checks for system `pre-commit` installation via `command -v pre-commit`. If missing, installs it via `pip install pre-commit`.
2. Registers hooks in `.git/hooks/pre-commit` via `pre-commit install`.

### Active Pre-Commit Hooks (`.pre-commit-config.yaml`)

Every commit is gated by 9 automated checks:

| Hook ID | Source Repository | Purpose | Enforcement Rule |
| :--- | :--- | :--- | :--- |
| **`check-yaml`** | `pre-commit/pre-commit-hooks` | Validates syntax of YAML configuration files | Fails on invalid syntax |
| **`check-added-large-files`** | `pre-commit/pre-commit-hooks` | Prevents accidental commits of large binaries | Blocked if file size > 1,000 KB |
| **`check-merge-conflict`** | `pre-commit/pre-commit-hooks` | Detects unmerged conflict markers (`<<<<<<<`, `=======`) | Blocked if conflict markers remain |
| **`check-case-conflict`** | `pre-commit/pre-commit-hooks` | Prevents filename case collisions on case-insensitive OS | Blocked if collisions detected |
| **`mixed-line-ending`** | `pre-commit/pre-commit-hooks` | Normalizes text line endings | Automatically converts CRLF to `LF` |
| **`detect-private-key`** | `pre-commit/pre-commit-hooks` | Prevents committing unencrypted private keys (`id_rsa`, etc.) | Hard block on credential patterns |
| **`clippy`** | `doublify/pre-commit-rust` | Enforces Rust linting standards | Runs `cargo clippy --all-features -- -D warnings` |
| **`cargo-check`** | `doublify/pre-commit-rust` | Verifies compilation integrity across all features | Runs `cargo check --all-features` |
| **`prettier`** | `pre-commit/mirrors-prettier` | Formats `Cargo.toml` manifests (excluding `Cargo.lock`) | Enforces uniform TOML formatting |

```bash
make deploy-testnet

# 2. Initialize the Shade hub with your administrator public key
```

```bash
# Check if contract is currently paused
make is-paused-shade NETWORK=testnet

# Trigger emergency pause
make pause-shade ADMIN=GBRAX2C6K4P6V7YQ5M8Z9W1D2F3H4J5K6L7M8N9P0Q1R2S3T4U5V6W7X NETWORK=testnet

# Confirm paused status
make is-paused-shade NETWORK=testnet
```
